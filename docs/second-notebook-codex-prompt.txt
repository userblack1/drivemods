3. Авторизуй GitHub через собственный вход владельца/Git Credential Manager либо подключённый GitHub-инструмент. Если используется другой аккаунт, сообщи его username для приглашения. Чужие токены и cookie не копируй.

6. После подключения выполняй конкретные задачи владельца: локальные изменения, тесты, аудит, коммит/PR/CI и выпуск на сервер. Не выводи банковские/бот-секреты и не выполняй покупки или переводы без отдельного разрешения на соответствующее финансовое действие.
