Тема: Автоматическое оформление лицензий для дилерского аккаунта

Здравствуйте!

Нам нужно оформлять лицензии круглосуточно после подтверждённой оплаты наших клиентов. Для нашего аккаунта сейчас подтверждены цены MB-S5WM FULL — 90 USD и ECO — 60 USD.

Вход в кабинет, чтение собственных записей и обычная оплата Stripe проверены. Для надёжной автоматизации нужны следующие сведения:

1. Поддерживаемый способ создавать лицензию из Device ID и получать точный ID созданной записи в ответе. Как передать и затем прочитать наш уникальный номер заказа и SHA-256 исходного файла? Есть ли ключ идемпотентности или поиск по номеру запроса, чтобы не создать дубль после сетевого обрыва?
2. Способ создать платёж ровно для одной указанной лицензии, проверить подтверждённую оплату и скачать файл именно этой лицензии. В текущих прочитанных GET_ONE отсутствуют поля deviceId и dealerComment, а бинарный файл непрозрачный; нужна документированная привязка устройства к записи.
3. Способ автоматической закупки без повторного ввода карточных реквизитов: поддерживаемый API, согласованный баланс/постоплата либо списание ранее сохранённого платёжного метода на вашей стороне Stripe. В доступной Checkout Session не настроены Customer/SetupIntent/setup_future_usage. Хранить CVC или обходить банковское подтверждение мы не будем. Если банк запросит подтверждение, нужен явный статус, позволяющий дождаться его без повторного списания.
4. Лимиты параллельной работы, правила повторов, срок жизни сессии и порядок обработки ошибок. Несколько клиентов могут оплатить одновременно; каждая выдача должна быть связана с одним заказом и одним устройством.

Мы не просим доступ к вашим секретным ключам Stripe, данным других дилеров или закрытой серверной логике. Подойдёт ограниченная официальная интеграция для нашего аккаунта либо подтверждённый порядок работы с балансом/постоплатой.

Просим направить запрос специалисту по дилерскому кабинету и интеграции платежей.

Спасибо!
